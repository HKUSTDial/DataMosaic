02 / FIVE STEPS

五步，从问题走到答案。

先拆解问题。再为每个子问题选择结构、检索证据、抽成结构化数据，并推理出答案。

01

问题分解

拆解用户输入的问题，规划步骤，得到多个子问题。

02

结构选择

按子问题选择合适的数据结构，支撑后续的信息抽取和推理。

03

检索

按子问题在文档中查找相关信息，得到数据片段。

04

抽取

从选定的数据结构和得到的数据片段中抽取信息，形成结构化数据。

05

推理

基于结构化数据得到当前子问题的答案，再把所有子答案汇总为最终答案。

过程中会检查：子问题是否还能优化，结构是否合理，信息是否充分，结构化数据是否合理。

03 / SEE IT IN ACTION

从文档，到分析过程。

上传文档并输入问题，观看系统自动完成问题分解、结构选择、证据检索、信息抽取与推理。

当前开源实现聚焦文本提问与文档分析；论文讨论的多模态框架是更广泛的研究愿景。

04 / QUICK START

在本机探索。

按仓库说明安装依赖并配置模型密钥，然后分别启动前后端。

  1. 01

    获取代码与依赖

    git clone https://github.com/zzhang393/StructMosaic.git
cd StructMosaic
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS / Linux: source .venv/bin/activate
pip install -r requirements.txt
  2. 02

    配置并启动后端

    参照仓库配置说明填写模型密钥，后端默认运行于 5000 端口。

    cd document_chat_app/backend
python app.py
  3. 03

    在新终端启动前端

    cd StructMosaic/document_chat_app/frontend
npm install
npm start

    浏览器访问 http://localhost:3000。
