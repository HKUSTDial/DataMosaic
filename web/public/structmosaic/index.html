02 / EXTRACT · REASON · VERIFY

让每一步，都可以检查。

论文方法：结构优先、分工协作、逐步验证。

  1. PLAN分解任务
  2. EXTRACT抽取证据
  3. REASON基于结构推理
  4. VERIFY检查中间结果

仓库提供简化的文档分析流水线，涵盖规划、检索、抽取、推理与 Thinking 智能体。

04 / QUICK START

在本机探索。

按仓库说明安装依赖并配置模型密钥，然后分别启动前后端。

  1. 01

    获取代码与依赖

    git clone https://github.com/zzhang393/StructMosaic.git
cd StructMosaic
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS / Linux: source .venv/bin/activate
pip install -r requirements.txt
  2. 02

    配置并启动后端

    参照仓库配置说明填写模型密钥，后端默认运行于 5000 端口。

    cd document_chat_app/backend
python app.py
  3. 03

    在新终端启动前端

    cd StructMosaic/document_chat_app/frontend
npm install
npm start

    浏览器访问 http://localhost:3000。
