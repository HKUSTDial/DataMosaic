01 / HOW IT WORKS

五个智能体，跑完同一条闭环。

文档、模式和约束一起进入。编排器调度实体抽取、关系抽取、约束校验和数据修复；违规只回到出错的部分，直到数据库满足约束。

01

编排器

按信号调度另外四个智能体，留下每一轮快照，直到交出最终数据库。

02

实体抽取

对照模式，从文档里找出实体和属性，写成能放进表里的记录。

03

关系抽取

在实体之间补上模式要求的关系，让外键和引用对得上。

04

约束校验

用 MCP 插件检查结构、类型、取值、引用和时间，把违规标出来。

05

数据修复

只对违规涉及的部分重新抽取，不把整批文档重跑一遍。

  • structure结构
  • type类型
  • value取值
  • logic逻辑
  • format格式
  • temporal时间
  • reference引用
  • aggregation聚合
  • data quality数据质量

支持通过 Web 界面完成工作流，也可作为独立 Python 库集成进现有系统。

02 / SEE IT IN ACTION

从文档，
到可用的数据库。

下面这段大约一分多钟，对应界面里的一次完整操作：选文档、给模式、看闭环、查结果。

  1. 在文档库里选中这次要处理的文件。
  2. 用表单、JSON 或自然语言给出模式和指令。
  3. 选定模型，以及串行、并行或自动的运行方式。
  4. 开始后，抽取、校验和修复的步骤实时展开。
  5. 完成后查看快照、违规与修复，并导出数据库。

03 / QUICK START

在本机跑起来

需要 Python 3.8+、Node.js 18+，以及一把大模型密钥：OpenAI 兼容接口、DeepSeek，或通义千问 / DashScope。以下命令在 DataMosaic 目录中执行。

  1. 01

    安装 Python 依赖

    虚拟环境建在仓库根目录。

    python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
  2. 02

    填写密钥

    复制示例文件后改成自己的密钥。仓库只带示例，不带 llm/.env。

    cp llm/.env.example llm/.env
    API_KEY=sk-...
API_URL=https://api.openai.com/v1
DEEPSEEK_KEY=...
DEEPSEEK_URL=https://api.deepseek.com
QWEN_KEY=...
QWEN_URL=https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions
  3. 03

    启动后端

    REST 在 http://localhost:5000，实时信号在 ws://localhost:8765。

    ./scripts/start_backend.sh
# or
cd backend && python app.py
  4. 04

    启动前端

    另开一个终端。浏览器打开 http://localhost:3000。

    ./scripts/start_frontend.sh
# or
cd frontend && npm install && npm start

在 Windows 上激活虚拟环境用 .venv\Scripts\activate。启动脚本是 shell，也可以直接用上面每一段里的手动命令。

04 / EVALUATION

四个数据集上的评测

全系统评测和只调用大模型的基线是两条命令。指标是 Precision、Recall、F1，以及 0–100 的 LLM-Score。对照结果写在仓库的 results.md。

  • FinanceDB金融
  • LegalDB法律
  • PaperDB论文
  • StudentDB学生
python test_dataset_evaluate.py --dataset FinanceDB --case case1 --model gpt-4o
python llm_evaluate.py --dataset FinanceDB --case case1 --model gpt-4o
参数含义
--datasetFinanceDB、PaperDB、StudentDB 或 LegalDB
--case数据集中的案例，例如 case1
--model模型名，例如 gpt-4o、claude-3-5-sonnet、qwen2.5-72b-instruct
--run_name自定义本次输出的运行标识

update_experiment/ 里还有一组模式变更实验，覆盖字段的新增、删除和更新。
